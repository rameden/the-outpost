The crew

Six specialists who know their trade, and stay in it.

Not one assistant but six other pairs of hands. Each has a fixed identity, its own memory, its own workspace and its own limits. Ask one for work outside its trade and it names the teammate who should do it.

Same crew, same work, any costume: pick one in Settings. In the film they wear the Starship one.

The kit

Mission control, at localhost.

A dashboard for the whole outpost: conversations filed under projects, a live feed, plans you approve with a button, a file pane, a terminal along the bottom, and a layout you arrange yourself.

Say yes from anywhere

Approve a plan from your phone while you're out. The crew keeps working; the outpost stays yours.

Memory as a map of stars

Three layers that last. Each crew member grows its own memory, and you can browse it as a constellation.

A router picks the model

Pick Auto and it sizes up each task: Economy, Balanced or Quality. Most of the crew starts on Sonnet, the Test Pilot on Opus.

Leave it running

Jobs on a schedule and a night shift that works while you sleep, with reports waiting when you're back.

From a note to a pull request

Tickets of its own, worked to a branch and a pull request that waits for you, and a look back when one's done.

As many outposts as you need

One for work, one for home, each with the name you give it. The star chart lists them all and starts the one you pick.

The rules

Nothing leaves the outpost without your click.

Clear limits, kept by the outpost's own code. An agent can't talk its way past them: the outpost's source is read-only to the crew, so nothing it reads can loosen them.

Secrets stay put

File tools never read .env, private keys or credentials, and your keys are left out of every command the crew starts.

Shell asks first

Commands need your OK, stop after two minutes, and stop when you press Stop. A sandbox is there if you want it.

Read-only git

Everyone can run status, diff, log and blame. Nobody pushes on their own.

No trampling

Parallel quests can't overwrite each other. A file another quest changed has to be read again first.

Pages are information

Web pages, files and connector results are never taken as instructions, and suspected prompt injection is flagged.

Budgets hold

Spending is tallied after every reply, across every quest, and the run stops when the budget is reached.

Get Outpost

Claim your ground. It takes five commands.

Outpost is free and open source. It runs on your Claude Pro or Max plan through Claude Code, or on an Anthropic API key, and you pay only for the model calls, the same as using Claude yourself.

Download Outpost (.zip) View on GitHub
Terminal
  1. git clone https://github.com/rameden/the-outpost.git && cd the-outpostOr unzip the download and open a terminal in its folder.
  2. npm install -g @anthropic-ai/claude-codeOnce, if claude isn't on your PATH yet. Skip it on an API key.
  3. npm install
  4. claude auth loginOn an API key instead, skip this and connect Anthropic under Settings → Models once the outpost is open.
  5. npm startThe star chart opens in your browser. Launch your first outpost (it's called Mae until you rename it) and you land in mission control, signed in.
