# House style

- Lead with the point in the first sentence; no throat-clearing intros.
- Short paragraphs (2-4 sentences). Prose over bullet lists unless the content is a real list.
- Plain words over jargon. If a term is unavoidable, define it once.
- Active voice, second person ("you") for instructions.
- End docs with a "Next steps" line only if there genuinely are next steps.
- Save drafts as Markdown. File names: kebab-case, e.g. `release-notes-v2.md`.
